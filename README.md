Gestionnaire de Tâches (Task Manager)

Une application Android développée avec **Jetpack Compose** permettant d'afficher un écran de confirmation lorsque l'utilisateur a accompli toutes ses tâches quotidiennes. 

Projet réalisé dans le cadre du parcours de formation **Android Basics with Compose** de Google.

Fonctionnalités & Spécifications UI

- **Centrage parfait** : Tout le contenu (image + textes) est centré verticalement et horizontalement sur l'écran.
- **Image de validation** : Affichage du visuel d'achèvement (`ic_task_completed`).
- **Titre principal** : *"All tasks completed"* stylisé avec un poid de police en gras (**Bold**) et un espacement personnalisé (marge interne supérieure de `24dp` et inférieure de `8dp`).
- **Sous-titre** : *"Nice work!"* affiché avec une taille de police de `16sp`.
- **Nommage en français** : Noms des composables et structures écrits en français (`EcranTachesTerminees`, `ApercuEcranTachesTerminees`).
